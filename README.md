# Financial Dashboard

An interactive financial dashboard designed to monitor business performance and make key financial metrics easier to understand. It brings measures such as gross sales, profit, cost of goods sold (COGS), units sold, and manufacturing costs into one place.

## Project Overview

This project presents financial and sales data through key performance indicators (KPIs) and interactive visualisations. It helps users explore business performance over time and compare results across countries.

## Project Objectives

- Monitor overall sales and profitability.
- Understand how costs affect business performance.
- Track the quantity of products sold.
- Analyse monthly changes in costs and other financial measures.
- Present important business information in a clear, interactive format.

## Key Performance Indicators

| KPI | Description |
|---|---|
| Gross Sales | Total sales value before deductions. |
| Profit | The profit amount calculated in the report. |
| Cost of Goods Sold (COGS) | The direct cost associated with the goods sold. |
| Units Sold | Total quantity of products sold. |
| Manufacturing Cost | Cost associated with manufacturing products. |

*The exact calculation of each KPI depends on the formulas and fields used in the report.*

## Dashboard Features

- KPI cards to provide a quick overview of business performance.
- Visual analysis of sales, profit, and costs.
- Country-wise comparisons.
- Monthly trend analysis.
- Interactive visuals that allow users to explore different aspects of the data.

## Tools and Technologies

- **Microsoft Power BI** – dashboard creation, data visualisation, and interactive reporting.
- **Git** – version control.
- **GitHub** – project hosting and source-code management.

## How to View the Dashboard

1. Clone or download this repository.
2. Find the Power BI report file (`.pbix`) in the project files.
3. Open the file using **Power BI Desktop**.
4. Use the report visuals and available filters to explore the data.
