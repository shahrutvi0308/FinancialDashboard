## 📌 About the Project

The **Financial Dashboard** is a Power BI project created to present important business and financial information in an interactive and easy-to-understand format. It brings key performance indicators (KPIs) and visual reports together so users can review overall performance and explore the data by product, country, and month.

The report includes dedicated pages for profit, sales and expenses, unit analysis, sales details, profit details, units details, COGS details, manufacturing cost details, and gross sales details.

## 🎯 Project Objectives

- Track key financial performance indicators in one place.
- Analyse sales and profit across different countries and products.
- Monitor units sold and understand monthly sales patterns.
- Review Cost of Goods Sold (COGS) and manufacturing costs.
- Use interactive report pages and filters to explore business performance.

## 📈 Key Performance Indicators

| KPI | What it shows |
|---|---|
| Total Sales | Overall sales value displayed in the report |
| Total Profit | Overall profit displayed in the report |
| Total Units Sold | Total quantity of units sold |
| Total COGS | Cost of Goods Sold |
| Total Manufacturing Cost | Manufacturing cost displayed in the report |
| Total Gross Sales | Gross sales value displayed in the report |

## 🧭 Report Pages

The Power BI report contains the following pages:

- **Profit** – high-level financial performance and product/country comparisons.
- **Sales and Expenses** – sales and expense analysis.
- **Unit Analysis** – overview of unit performance.
- **Sales Detail** – detailed sales information.
- **Profit Details** – detailed profit analysis.
- **Units Details** – monthly, product-wise, and country-wise unit analysis.
- **COGS Details** – Cost of Goods Sold analysis.
- **Manufacturing Cost Details** – manufacturing cost analysis.
- **Gross Sales Details** – gross sales analysis.

## 🛠️ Tools Used

- **Microsoft Power BI** – data visualisation, KPI reporting, and interactive dashboard development.
- **Git** – version control.
- **GitHub** – project hosting and documentation.

## ▶️ How to View the Dashboard

1. Clone or download this repository.
2. Locate the Power BI report file (`.pbix`), if it is included in the repository.
3. Open the `.pbix` file in **Power BI Desktop**.
4. Navigate through the report pages and use the available filters to explore the data.

> **Note:** The screenshots above provide a preview. The interactive report can be explored by opening the `.pbix` file, if included.
